# LetterCraft ✉️

LetterCraft is an AI-powered cover letter generator that helps job seekers create personalized, professional cover letters in seconds. Users simply input their background information and the job they're applying for, and LetterCraft instantly generates a tailored cover letter ready to use. The app is designed to save time and reduce the stress of the application process, especially for students and early-career professionals breaking into the industry. It was built as a personal project to combine my interest in AI tooling with practical career utility. LetterCraft is fully deployed and accessible from any device with no setup required.

## 🔧 How to Run Locally

```bash

cd coverletter
```

Then open `index.html` in your browser. Add your Groq API key where prompted in the config.
